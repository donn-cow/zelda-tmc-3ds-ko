# 한글패치 롬 지원 (Korean translation patch)

이 빌드는 일본판(BZMJ) 기반 한글패치 롬
`The Legend of Zelda - Fushigi no Boushi(K)_ver1.0.gba`
(SHA-1 `c15e3905cf64b6a1fdfe9118346e1ff5dcfa8ee8`)을 그대로 읽어서 실행합니다.

## 사용법

1. CIA/3DSX를 설치합니다.
2. SD 카드 `sdmc:/3ds/The Minish Cap 3DS/` 폴더에 한글패치 `.gba` 파일 **하나만** 넣습니다.
   (USA/EU 롬이 같이 있으면 먼저 발견된 롬이 실행됩니다.)
3. 실행하면 로그에 `Korean translation patch detected`가 표시되고 한글로 진행됩니다.
4. 세이브는 일본판 계열 전용 파일 `tmc_jp.sav`에 따로 저장됩니다.

## 동작 원리

한글패치는 롬 안의 ARM 코드(글리프 뱅크 조회, 제어코드 해석, 한글 이름 입력 키보드,
이름 출력 루틴)를 고쳐서 동작합니다. 이 포트는 롬의 코드를 실행하지 않고 C로 다시 구현된
엔진을 쓰기 때문에, 패치가 바꾼 동작을 C로 옮겼습니다. 폰트·텍스트·완성형 음절표·자모 조합표·
키보드 그래픽은 모두 사용자의 롬에서 실행 시점에 읽어오며, 포트에 패치 데이터는 포함되지 않습니다.

| 패치 내용 (롬 주소) | 포트 구현 |
|---|---|
| 글리프 뱅크 표 9개→16개 (`0x5F104` → `0xDC9F00`) | `port_rom.c` 에서 16뱅크 로드 |
| 제어코드 `0B`~`0E` → 한글 뱅크 4~7, `0F 4X nn` → 뱅크 9~15 | `text.c` `GetCharacter` |
| 뱅크 3 이상 2칸 폭 글리프 (`cmp #4` → `#2`) | `text.c` `sub_0805F25C`, `GetFontStrWith`, `sub_0805F7DC` |
| 버튼 아이콘 뱅크 7 → 3 (`0x567FA`) | `message.c` |
| 스타일 글리프 표 (`0x5F804` → `0xE57C00`) | `port_rom.c` |
| 대사 속 플레이어 이름 변환 훅 (`0x5EFA2`) | `text.c` + `Port_Kr_FormatName` |
| 파일 선택 화면 이름 출력 (`0x505D8`) | `fileselect.c` `sub_0805070C` |
| 키스톤 합체 화면 이름 (`0xA424C`) | `kinstoneMenu.c` |
| 한글 이름 입력(자모 키보드, 겹받침/이중모음, 백스페이스 분해) (`0x51134`, `0x51324`, `0x511FA`) | `fileselect.c` 하단 `Port_Kr_*` |
| 피규어 확률 하한 비교 수정 (`0x88238`) | `figurineDevice.c` |

또한 3DS 포트는 원래 일본판 롬을 거부했으므로 `main_3ds.c`에서 BZMJ를 허용하고,
`port_rom.c`의 JP 오프셋 표 중 비어 있던 항목(음악 테이블, 충돌, 바람항아리, 경비병 등)을
Project Picori 업스트림 값과 롬 탐색(음악 테이블 `0x9F3D3C`)으로 채웠습니다.
